# The `html` stack — implementation plan

Spec: `docs/superpowers/specs/2026-10-14-html-design.md`. Each task writes its check first,
sees it fail, then builds until `./check` passes, and ends in one commit holding the check and
the code.

The backlog entry "The `frontend` domain never reaches a project's HTML" is this slice; task 2
deletes it. The entry "`./check 40` counts a module that does not exist as zero lines" touches
the budget check and is left there knowingly: `html` ships no rule, so the UI worst case does
not name it.

- `checks/70-init.sh`: the `apps/web` case also asserts `  - "apps/web/**/*.html"` in the

- Commit: `feat(frontend): load the accessibility rule on html files`
